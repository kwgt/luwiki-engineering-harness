# その他の附則

## AIエージェントの振るまい
- AIエージェントは、推測・仮定・未確認の情報を確定した事実として扱ってはならない。これらを用いる場合は、その性質を明示すること。
- AIエージェントは、既存の決定事項を独断で変更してはならない。変更が必要と判断した場合は、その理由と影響をユーザに提示し、必要な承認を得ること。
- AIエージェントは、指示された作業の目的達成に必要な範囲を超えて、変更対象や作業内容を独断で拡大してはならない。
- AIエージェントは、文書または成果物を変更した場合、変更内容と直接関連する既存の文書・成果物との整合性を確認すること。
- AIエージェントは、判断に必要な情報が不足している場合、独断で補完するのではなく、既存資料の確認またはユーザへの問い合わせによって解消すること。
- AIエージェントは、実施していない作業や検証を、実施済みとして報告してはならない。未実施の検証がある場合は、その事実を明示すること。

## 状態バナーのフォーマット
以下のようなフォーマットで設置すること。

```markdown
> - **状態**: ミッション「セキュリティホール対策(1)」完了・正式クローズ（2026-10-16）
> - **次のアクション**: なし
```

## ミッションワークスペースの索引スタイル
以下のようなフォーマットで設置し、シンプルさを保つこと。

```markdown
### OP1: REST APIのパス認可と監査の整合
- [[OP1マイルストーン計画]] — **承認済み (2026/10/10)**
- [[OP1-MS1タスクリスト]] — **完了 (2026/10/11)**
  - [[OP1-MS1タスクリスト/グループ1作業記録]]
  - [[OP1-MS1タスクリスト/グループ2作業記録]]
  - [[OP1-MS1タスクリスト/グループ3作業記録]]
```

- 計画書やタスクリストなどトップレベルに置かれているアイテムには状態を表す注釈を付けるが、配下のアイテムには注釈は必要ない。
- タスクリスト配下の成果物や作業記録は着手順にソートされていること。

## その他
- レポジトリで管理される文書は、異なる管理領域に存在する情報への依存を原則として避け、当該レポジトリ内で内容を理解・利用できる状態を維持すること。
